Iconography
Inline SVG only. 1.5px stroke, rounded caps. No emojis, no icon fonts, no PNG icons.
Zero Emojis. Zero Icon Fonts. Zero PNG Icons.

Every surface: website, social graphics, email, presentations. Font Awesome and PNG sprite sheets are banned. SVGs must be inlined in HTML — not externally src-linked.

SVG in CSS — Encoding Rule (from project history)

When using SVG inside a CSS url() declaration, single quotes must be encoded as %27 or replaced with double quotes. Unencoded quotes cause silent CSS parser failures that break the entire style block. Prefer CSS gradient equivalents over SVG data URIs wherever possible.

Fragment Injection & Path Resolution

How Fragment Injection Works

Every page has <div id="site-header"></div> and <div id="site-footer"></div>. global.js fetches header.html and footer.html and injects into those divs at load. Links in the fragments are resolved by rewriteFragmentLinks().

Never Use <base href>

The <base href> tag was tried and abandoned — it breaks all asset paths site-wide and causes regressions across pages. Use rewriteFragmentLinks() exclusively. This is a hard rule from project history.

/* global.js — domain-agnostic base path */ const src = document.currentScript.src; const base = src.substring(0, src.lastIndexOf('/') + 1); async function loadFragment(id, file) { const html = await (await fetch(base + file)).text(); document.getElementById(id).innerHTML = html; rewriteFragmentLinks(id); } function rewriteFragmentLinks(id) { document.getElementById(id) .querySelectorAll('a[href]') .forEach(a => { if (!a.href.startsWith('http')) a.href = base + a.getAttribute('href'); }); }

18
Do’s & Don’ts
Non-negotiable rules. Every collaborator, contractor, and team member must know these.
Always spell it “Grey”
British spelling. Every file, document, CSS variable, social handle. “GreySphere” — not “GraySphere”. No exceptions.
Never write “Gray”
“GraySphere”, “Gray Sphere”, “graysphere” — all wrong. Not even informally. Non-negotiable.
Use the wordmark exactly as defined
Use “GreySphere.” with the amber dot in the approved colour combinations. Maintain clear space. Scale proportionally only.
Never modify the wordmark
No icon alongside the text. No retype in another font. No drop shadows, outlines, distortion, or rotation. No removing the dot. No recolouring the dot (except on amber bg).
Inline SVG only for all icons
1.5px stroke, rounded caps, 24px default, inlined in HTML. Navy primary icons. Amber accent icons.
Zero emojis, anywhere
No emojis on website, social graphics, email, presentations. Icon fonts are also banned. PNG icons are banned. SVG only, always.
Use only DM Serif Display + General Sans
Display headings → DM Serif Display. Body, UI, captions → General Sans. Two fonts. No exceptions in any medium or channel.
Never introduce new fonts
Inter, Roboto, Poppins, Montserrat, Space Grotesk, Lato, Open Sans — all banned. System fonts are emergency fallbacks only.
One breakpoint: max-width 900px only
All responsive CSS uses @media (max-width: 900px). Desktop layout is the default from 901px to 1440px. No additional breakpoints.
Never use 1024px as a breakpoint
1024px, 768px, 480px — none of these breakpoints exist in GreySphere’s CSS. 900px is the only one. Raise any deviation with the team.
Derive base path from script src
In global.js, base path comes from document.currentScript.src. Domain-agnostic. Works on GitHub Pages and any future custom domain without changes.
Never hardcode paths or use <base href>
Hardcoding /consultingfirm/ breaks on a custom domain. <base href> was tried and abandoned — breaks all asset paths site-wide. Use rewriteFragmentLinks() only.
Encode SVG quotes in CSS url()
Single quotes inside SVG data URIs in CSS url() must be encoded as %27 or replaced with double quotes. Prefer CSS gradients over SVG data URIs.
Legal terms don’t belong on public pages
Payment terms, refunds, and SLAs belong in client-specific agreements, not the public Terms of Service page. Jurisdiction: Bangalore, India. Bangalore courts govern all disputes.
